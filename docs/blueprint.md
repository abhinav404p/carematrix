# **App Name**: carematrix

## Core Features:

- User Authentication: Secure user registration and login using Firebase Authentication.
- Service Listings: Display available home-care services with detailed descriptions and pricing.
- Booking System: Enable users to book services, select dates, and specify booking duration (daily/monthly).
- Job Application Form: Allow job seekers to submit applications with personal details, skills, and experience.
- Real-time Booking Updates: Provide real-time updates and notifications for booking confirmation and status changes.
- Admin Dashboard: Admin interface to manage service bookings, approve/reject service providers and manage job applications.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) to evoke trust and tranquility, essential for a home-care service.
- Background color: Very light blue (#F0F8FF), almost white, provides a clean, calming backdrop.
- Accent color: Muted green (#90EE90) for subtle highlights and action items, ensuring it doesn’t overpower the serene blue tones.
- Body and headline font: 'PT Sans', a humanist sans-serif font offering a blend of modern aesthetics and gentle readability, which will render a comfortable reading experience for a diverse user base.
- Use clean, friendly icons to represent each service category.
- Responsive grid layout that adapts to different screen sizes.
- Subtle transitions and animations for a smooth user experience.
